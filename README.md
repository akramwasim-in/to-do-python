# 📝 Python To-Do List CLI App (with Pandas)

A interactive Command Line Interface (CLI) To-Do List application built in Python.
It uses the `pandas` library to display tasks in a clean tabular format.

---
## ⚡ Features
- **Add Tasks:** Quickly add new tasks to your daily list.
- **Update Tasks:** Modify existing task names.
- **View Tasks:** Render all active tasks using a Pandas DataFrame with 1-based indexing.
- **Delete Tasks:** Remove completed or unwanted tasks.
- **Input Handling:** Includes basic error handling for non-numeric menu inputs.
